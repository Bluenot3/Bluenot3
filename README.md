<details>
<summary><sub><strong>How this profile is built</strong></sub></summary>

<br />

Every visual here is a self-contained animated SVG generated by [`scripts/build_profile_assets.py`](./scripts/build_profile_assets.py). No GIFs, no video, no JavaScript, no external requests.

- **Responsive.** Wide graphics ship a portrait phone layout too, served with `<picture>` and a `max-width: 600px` media query, so type stays readable on a phone. Buttons, tiles and links use fixed heights so they reflow into a grid instead of shrinking.
- **Type.** Inter Display, Instrument Serif and JetBrains Mono (SIL OFL), subset to the exact glyphs each file uses and embedded as WOFF2.
- **The globe.** About 2,500 dots, roughly 1,400 of them land from Natural Earth. Each latitude ring is one path on a unit circle, projected with `scale(r, r·sin(tilt))` and spun by a single `animateTransform`; `non-scaling-stroke` keeps the dots round, and a per-ring clip at the true horizon hides the far side. Flight arcs from Washington, D.C. are elevated great circles, re-projected every 5° of rotation into keyframed Bézier paths so they ride the spinning planet and fade at the limb.
- **Motion.** CSS keyframes and SMIL only: one-shot entrances, odometer counters with live mini-charts, a radar sweep that pings each product as it passes, a laser-traced monogram. Everything honors `prefers-reduced-motion`, and nothing that moves uses a blur filter.

</details>
