<summary><sub><strong>How this profile is engineered</strong></sub></summary>

<br />

Every visual on this page is a hand-built, self-contained animated SVG generated by [`scripts/build_profile_assets.py`](./scripts/build_profile_assets.py). No GIFs, no video, no JavaScript, no external requests:

- **Fonts** (Unbounded, JetBrains Mono, Inter; SIL OFL) are subset to the exact glyphs each file uses and embedded as WOFF2.
- **The ZZ monogram** is vector geometry traced from the master mark, laser-drawn with `stroke-dashoffset` while a spark rides the outline via `animateMotion`.
- **The globe** is ~2,900 dots (about 1,200 of them land, from Natural Earth). Each latitude ring is one path on a unit circle, projected with `scale(r, r·sin(tilt))` and spun with a single `animateTransform`. `non-scaling-stroke` keeps the dots round, and a per-ring clip at the true horizon hides the far side. 45 rotations draw the whole planet, and the D.C. label counter-rotates so it stays upright.
- **Motion** is CSS keyframes plus SMIL: odometer digit columns, typed terminal clips, orbiting satellites. CSS motion honors `prefers-reduced-motion`.
- **Rendering budget:** no blur filters on anything that moves, so repaint stays cheap.

</details>
